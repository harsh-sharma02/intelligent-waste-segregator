# Intelligent Waste Segregation System

## Overview

The Intelligent Waste Segregation System is an automated waste-sorting prototype that combines mechanical handling, computer vision, artificial intelligence, embedded control, and actuator-based sorting.

The project was developed as a course project and involved designing and building a complete physical prototype rather than developing only a software classification model.

The system uses a conveyor-based mechanical structure to transport waste, a camera-based vision system to capture the waste item, AI/image-processing techniques to classify the item, and an embedded controller to actuate the appropriate mechanism for physical segregation.

The developed system is capable of classifying waste into categories including:

- Plastic
- Metal
- Paper

---

## Problem Statement

Manual waste segregation is labor-intensive and can result in inconsistent sorting. The objective of this project was to develop a compact automated system capable of identifying and physically separating waste based on its category.

The project combines perception and physical actuation into a single automated pipeline:

```text
Waste
  ↓
Conveyor Transport
  ↓
Image Acquisition
  ↓
Image Processing
  ↓
AI Waste Classification
  ↓
Embedded Controller
  ↓
Actuator
  ↓
Physical Segregation
```
